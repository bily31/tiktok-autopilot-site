Privacy Policy

Last updated: October 1, 2026 · Applies to: tiktok-autopilot

1. Overview

tiktok-autopilot is a personal developer tool that publishes video content to a TikTok account on behalf of the account owner. It is operated privately by the account owner for their own use.

2. Data We Collect

To publish content, the tool stores the OAuth access token and refresh token issued by TikTok. These tokens are the only user data retained. They are saved locally on the owner's device and are never transmitted to any third-party server operated by us.

No name, phone number, email address, password, message, comment, or follower data is collected, stored, or processed by this tool.

3. How Data Is Used

Tokens are used solely to authenticate requests to the official TikTok Content Posting API for uploading video files the owner has designated for publication. They are never used for advertising, profiling, analytics, or any other purpose.

4. Data Sharing

We do not sell, rent, trade, or otherwise share your data with third parties. All API requests go directly from the owner's device to TikTok's servers at open.tiktokapis.com.

5. Data Storage and Security

Credentials are stored in a local configuration file with restricted file permissions (0600) on the owner's device. No credentials are committed to version control or transmitted over the network by this tool.

6. Data Retention and Deletion

Tokens are retained until the owner deletes the local configuration file, or until TikTok invalidates them. Deleting the file permanently removes all stored data and requires the owner to re-authorize the tool.

7. Your Rights

This tool stores no personal information about you beyond authentication tokens. You may revoke access at any time through TikTok's "Manage Apps" settings, which immediately invalidates the stored tokens.

8. Children

This tool is not directed to anyone under 18 and collects no data from children.

9. Changes

Any changes to this policy will be posted on this page with an updated date.

10. Contact

Questions may be sent to the account owner via the TikTok account associated with this tool.
